# メモは既定で非公開。アプリ本体はクロールさせない。
#
# **/notes/ を Disallow してはいけない。** クロールを止めるとクローラが
# レスポンスの X-Robots-Tag: noindex を読めず、外部からリンクされた URL が
# 「内容なしの URL だけ」の形でインデックスされうる。
# 狙いはクロールの拒否ではなくインデックスの拒否なので、crawl は許して
# noindex を読ませる（docs/product.md 第6章）。
#
# /login（ホームページ）・/privacy・/terms は Google OAuth の同意画面に登録する公開ページ。
# 誰に読まれてもよく、Google の確認で取りに来られるので止めない。
User-agent: *
Disallow: /
Allow: /notes/
Allow: /login
Allow: /privacy
Allow: /terms
